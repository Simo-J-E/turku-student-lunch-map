Haluan sinun rakentavan kokonaan toimivan tuotantovalmiin web-sovelluksen Turun opiskelijaravintoloiden löytämiseen.

Älä tee pelkkää UI-demoa. Tee oikeasti toimiva sovellus, jonka voi julkaista GitHubin kautta ja jota voidaan käyttää oikeilla ruokalista- ja ravintolatiedoilla.

# Projektin idea

Sovellus näyttää kartalla kaikki Turun opiskelijaravintolat ja niiden päivän ruokalistat.

Opiskelijaravintolalla tarkoitetaan paikkaa, jossa opiskelija voi ostaa opiskelijahintaisen lounaan.

Esimerkiksi tällä hetkellä hinta voi olla noin:

- normaali opiskelijalounas 3,10 €
- deluxe / premium opiskelijalounas 5,80 €

Nämä hinnat EIVÄT saa olla kovakoodattuja sovelluksen logiikkaan, koska hinnat muuttuvat tulevaisuudessa.

Ravintolan opiskelijahinta haetaan tietolähteestä tai tallennetaan tietokantaan ja sen pitää olla helposti päivitettävissä.

Sovellus näyttää myös ravintolat, joissa on muu opiskelija-alennus, vaikka kyseessä ei olisi tavallinen Kelan opiskelijalounas.

# Ruokalista

Sovelluksen tärkein toiminto on tämän päivän ruokalistojen näyttäminen.

Hae ruokalistat oikeista lähteistä.

Prioriteetti:

1. virallinen API
2. ravintolan oma JSON/API endpoint
3. virallinen ruokalistasivu
4. HTML parseri/scraperi

Älä käytä satunnaisia epäluotettavia kolmannen osapuolen tietolähteitä, jos alkuperäinen lähde löytyy.

Jokaiselle ravintolaketjulle voidaan tehdä oma adapteri.

Esimerkiksi:

MenuProvider

interface MenuProvider {
  getRestaurants(): Promise<Restaurant[]>
  getMenu(restaurant: Restaurant, date: string): Promise<Menu>
}

Tee ravintolakohtaiset providerit esimerkiksi:

UnicaProvider
CompassProvider
SodexoProvider

jos nämä ovat tarpeellisia oikeiden Turun opiskelijaravintoloiden perusteella.

Älä oleta ketjuja etukäteen.

Selvitä oikeat lähteet.
